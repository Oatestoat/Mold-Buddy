# 🌱 Mold Buddy

**A Low-Cost Environmental Monitoring and Mold-Risk Awareness System**

Mold Buddy is a project designed to help people better understand indoor environmental conditions that may contribute to mold growth.

Developed as part of Alvernia University's Summer Undergraduate Research Fellowship (SURF) program, Mold Buddy combines environmental monitoring with an interactive educational app.

### 🌐 Try Mold Buddy

**[▶ Launch Mold Buddy](https://oatestoat.github.io/Mold-Buddy/)**

Click above to open the web app directly in your browser. No installation required!

### Features

- Temperature and humidity monitoring
- Room-specific environmental tracking
- Indoor and outdoor condition comparisons
- Historical readings and trends
- Educational information about moisture and mold prevention
- ESP32 and BME280 sensor integration

### About the Project

Mold Buddy is intended to support mold-risk awareness and education. It does not directly detect mold or mold spores.
